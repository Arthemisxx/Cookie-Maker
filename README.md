# Cookie-Maker

A simple web application that serves as a cookie configurator. The project has an educational purpose and was created for the practical learning of cookie mechanisms and management in web browsers. It was built in the Node.js environment using the Handlebars template engine and a simple CSS stylesheet.

### Requirements
* Node.js
* npm package manager

### Setup Instructions

1. Clone the repository:
`git clone https://github.com/Arthemisxx/Cookie-Maker.git`

2. Navigate to the project directory:
`cd Cookie-Maker`

3. Install dependencies:
`npm install`

4. Run the application:
`node index.js`

The application will be available in your browser at http://localhost:3000.
